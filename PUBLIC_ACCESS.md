# Доступ к модели

По умолчанию Docker публикует порт только на localhost. При публикации сервиса
за HTTPS-прокси задайте API_ACCESS_KEY: отдельный длинный случайный ключ,
не Hugging Face token. Пользователь вводит его в поле ключа на странице.
Браузер отправляет его в Authorization, не сохраняет в localStorage и не включает в URL.
Для прямых API-запросов используйте Authorization: Bearer <ключ>.

Оба маршрута /chat и /test-api используют ключ и общий лимит на IP:
RATE_LIMIT_REQUESTS запросов в минуту, по умолчанию 10. Ответ 429 содержит Retry-After.
Статика и /hello не расходуют квоту. Без API_ACCESS_KEY режим локальный без авторизации.

Лимитер хранится в памяти одного процесса и сбрасывается при перезапуске.
Для нескольких процессов нужен общий лимитер на прокси или в Redis. Настройте
доверенные IP прокси в Uvicorn; приложение само не доверяет X-Forwarded-For.
HTTPS обязателен при передаче ключа вне localhost. Это общий ключ для учебного
сервиса, а не система пользовательских аккаунтов.
